# NOT DEAD YET 🧟

**A first-person survival horror game built with Godot.**

## 🎮 About the Game

NOT DEAD YET is a survival horror game set in an abandoned college campus. Players must explore the environment, avoid a pursuing zombie, collect an access keycard, and reach the main gate before time runs out.

## 🎯 Objective

- Explore the abandoned campus.
- Avoid the zombie.
- Manage noise while moving.
- Find the access keycard.
- Reach the main gate before the timer expires.

## 🕹️ Planned Controls

| Key | Action |
|---|---|
| W | Move forward |
| A | Move left |
| S | Move backward |
| D | Move right |
| Shift | Sprint |
| Mouse | Look around |
| Esc | Release the mouse |

## 🛠️ Built With

- Godot Engine 4.x
- GDScript
- Antigravity
- Git and GitHub

## ✨ Planned Features

- First-person movement
- Sprinting and noise mechanics
- Zombie detection and pursuit
- Health and damage system
- Keycard-based exit

## ▶️ How to Run

1. Install a compatible version of Godot 4.
2. Clone or download this repository.
3. Open Godot's Project Manager.
4. Import the project by selecting the `project.godot` file.
5. Open the project and run the main scene once it has been configured.
